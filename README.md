# luduvodb-project/frontend

The frontend for the LuduvoDB project.

## Developing

Clone the project:

```sh
git clone https://github.com/luduvodb-project/frontend.git --depth=1
# `--depth=1` only clones the current snapshot of the repository
# omitting `--depth=1` clones the full history
```

Install dependencies via npm, deno, bun, etc:

```sh
npm install
deno install
bun install
...
```

Start a development server:

```sh
npm run dev
deno run dev
bun run dev
...
```

Go to localhost:5173.
